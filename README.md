# data-science
Data Science Exercises

## Installation
* `Check` brew list | grep python
* `Python` brew install python@3.10
* `venv` 
    - create virtual environment if not created yet
    - /opt/homebrew/opt/python@3.10/bin/python3.10 -m venv venv310
* `activate` source venv310/bin/activate
* `Dependecies`
    - Modules will be created in virtual environment venv310 only
    - pip install boto3 botocore numpy pandas scikit-learn joblib requests
* `deactivate` deactivate
